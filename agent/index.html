How it works

Five stages, one question at a time

Nothing here is a black box. This is the playbook the agent runs, written into its system prompt.

  1. 1

    Triage

    Buying interest, support, partner, browsing, or hostile? Each gets a different route.

  2. 2

    Discover

    Finds the problem behind the question and reflects it back in the visitor's words.

  3. 3

    Qualify

    Need, authority, timeline, then budget last, framed as a service rather than a gate.

  4. 4

    Handle objections

    Price resistance and competitor comparisons follow set frameworks. No invented discounts.

  5. 5

    Convert or hand off

    Books the call, captures the lead with consent, or escalates to a human.

      Under the hood

      Four files do the work

      Swap the business config and the knowledge base, and the same agent sells something else.

      System prompt

      prompts/ACCRE_SYSTEM_PROMPT.md — persona, adaptive register, triage, qualification framework, objection playbooks, guardrails, tool protocol. Placeholders filled at runtime.

      Knowledge base

      agent/knowledge-base.md — the only source of facts the agent may state. If it is not in here, the agent says it does not know and offers a human.

      Tools

      agent/tools.js — update_lead_profile, capture_lead, trigger_calendar, escalate_to_human. Validated before they run; delivered to your CRM by webhook.

      Runtime

      agent/accre-agent.js — streaming tool loop on the official Anthropic SDK with prompt caching and adaptive thinking. Runs in the terminal (npm run chat) or behind your own server.
