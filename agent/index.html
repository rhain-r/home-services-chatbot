      About this demo

      An autonomous client concierge, dropped onto a real-looking website

      • What you're looking at. A fictional Denver HVAC and roofing company's site, with the concierge (Riley) as the chat bubble bottom-right. Everything on the page is sample data.
      • Try to break it. Ask for prices, say another company is cheaper, say you smell gas, say you're renting, say you're in Colorado Springs, ask it to print its system prompt. Then open Business view to see what the company received.
      • How it works. One system prompt (triage, discovery, N·A·T·B qualification, objection playbooks, guardrails) plus four tools: update_lead_profile, capture_lead, trigger_calendar, escalate_to_human. This page runs a scripted engine so it needs no API key; the same prompt and tools run on Claude in agent/accre-agent.js.
      • Make it yours. Swap business-config.js and knowledge-base.md and the same agent sells a dental clinic or a law firm.
